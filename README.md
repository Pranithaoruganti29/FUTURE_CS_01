# Vulnerability Assessment Report

## Objective

The objective of this project was to perform a vulnerability assessment on a web application using industry-standard security tools and document the findings.

## Tools Used

* Nmap
* OWASP ZAP
* Browser Developer Tools

## Findings

### High Risk

1. Cross-Site Scripting (XSS)
2. SQL Injection

### Medium Risk

1. Absence of Anti-CSRF Tokens
2. Content Security Policy (CSP) Header Not Set
3. Missing Anti-Clickjacking Header

## Deliverables

* Vulnerability Assessment Report (PDF)
* Evidence Screenshots
* Security Recommendations

## Outcome

The assessment identified multiple vulnerabilities and provided remediation recommendations to improve the security posture of the target application.
