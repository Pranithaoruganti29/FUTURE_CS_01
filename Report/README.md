# Task 1 - OWASP ZAP Vulnerability Scan

## Target Website
http://demo.testfire.net

## Tool Used
OWASP ZAP

## Vulnerabilities Identified

### 1. Cross Site Scripting (XSS)
- Risk: High
- Description: User input is reflected without proper validation.

### 2. SQL Injection
- Risk: High
- Description: Database queries may be manipulated through user input.

## Conclusion
The OWASP ZAP scan identified XSS and SQL Injection vulnerabilities in the target application.
